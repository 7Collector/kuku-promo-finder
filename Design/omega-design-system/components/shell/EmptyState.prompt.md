# EmptyState

Nothing here yet: one centred ink-3 line and, when there is something to do about it, one tertiary action. No illustration and no second sentence.

```html
<div class="om-empty-state">
  <div class="om-empty-state-text">No homework yet</div>
  <!-- optional tertiary button: Add task -->
</div>
```

Variants: with or without the action. 24 padding above and below, 8 between the line and the action.

Compose source: omega-kmp :ui, OmegaStates.kt, `EmptyState(text, actionLabel, onAction)`
